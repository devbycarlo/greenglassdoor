📖 How to Play Green Glass Door

Green Glass Door is a classic deduction game where an exclusive club only accepts items (and places) that satisfy a secret rule.

Example Gameplay

• Secret Rule: Item must contain double letters (e.g. Apple, Glass).
• Player 1: "I'm going to the beach and bringing Apples." -> APPROVED!
• Player 2: "I'm going to the beach and bringing Bananas." -> REJECTED!

Game Modes
  • Solo vs AI: The automated Bouncer picks a rule. Test items, request hints, and solve the rule code!
  • Party Host Mode: Pass the device around or host a live group! Use the secret rule generator, track players, and log decisions live.
Golden Party Rule: If you figure out the rule, don't spoil it! Keep making correct guesses or help host until everyone cracks it!
